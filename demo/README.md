# zarchive-py demo

Install the package, then run this script. It uses the installed `zarchive_py` module: format table, identify, zip create/list/read/verify/extract, a nested zip, 7z/rar/gzip/bzip2/za create, and a Windows self-extract trailer.

```sh
pip install zarchive-py
python demo.py
```

Files are written to `out` beside this script and replaced on each run.
